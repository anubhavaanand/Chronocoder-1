## RESOLVED: trailer wrapping — root cause and fix

Root cause of the wrap seen in #425: the merge commit reuses the PR body, and
GitHub hard-wraps long lines when composing that message.

Fix (proven on scratch repo, both trailers survive on ONE line):
    gh pr merge N --merge \
      --subject "<title> (#N)" \
      --body "Co-authored-by: metiquella <259600641+metiquella@users.noreply.github.com>
Co-authored-by: openhands <openhands@all-hands.dev>"

Verified:
    git log -1 --format="%(trailers:key=Co-authored-by,valueonly)"  -> both parsed
    cat -A -> one physical line each, no wrap

Note: #423/#424 trailers were italicised (`_Co-authored-by: ..._`) so they were
malformed at the source and can never count. #425 has a wrapped (2-line) metiquella
trailer. Use the --subject/--body form above for all future PRs.

Verification command after merge:
    git fetch -q origin && git log -1 --format="%(trailers:key=Co-authored-by,valueonly)" origin/master

## #273 — WebGL pointer listeners (merged)
Root cause chain that cost most of the session (all real bugs, not test noise):
  1. `<img data-gl-src>` has `pointer-events: none`, so listeners on it never
     fire — attach to `[data-gl-pointer]` host, else nearest ancestor whose
     computed pointer-events isn't `none`, else the img.
  2. The component started ONE rAF loop inside `boot()`; images added after
     mount (via MutationObserver) got a plane but never a loop, so their
     uniforms stayed at 0. Fixed by extracting `ensureLoop()` and calling it
     from the observer.
  3. jsdom: `update()` frustum-culls off-screen planes, so a test host with no
     box never animates. Give the host explicit width/height styles.
  4. Tests that replace `window.matchMedia` / `rafCallback` leak across cases;
     the #273 test must install its own RAF + matchMedia and append its host to
     `document.body` (the render container gets detached by cleanup).

Pitfall hit repeatedly: stripping `console.error` debug lines with a
`'DBG ' not in l` filter also deletes multi-line `console.error('DBG', {...})`
continuations, corrupting the file. Assert with tsc after any such bulk edit.

Co-authored-by trailers on ONE physical line each — confirmed with

## Pair Extraordinaire — verified criteria (source: github/community #207797)
Authoritative checklist from a user with "Pair Extraordinaire x3":
1. `Co-authored-by: Name <email>` in the **commit message footer** (not PR body).
2. Email must match co-author's verified email, or `ID+username@users.noreply.github.com`.
   (Plain `username@users.noreply.github.com` also works — confirmed on PR 426.)
3. Commit must be in a **merged PR**, not a direct push.
4. Merge method: squash merges often strip trailers → use **merge commit** or rebase.
5. **Delay: 24–72 hours after merge** before the badge appears.
6. Debug: check `?tab=achievements` (sidebar shows only ~4).

Our status: 2 valid (PR 322 + PR 426), threshold met → **just a lag issue**.
Do NOT create more PRs; wait 24–72h and re-check.
