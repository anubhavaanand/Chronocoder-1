# ChronoCoder: AI-Powered Mentor Chatbot for Python Learning

**Created by: Anubhav** ✨

ChronoCoder is a stunning Python-based educational chatbot that simulates **8 legendary programmers** including Ada Lovelace, Linus Torvalds, Grace Hopper, Alan Turing, Margaret Hamilton, Dennis Ritchie, Barbara Liskov, and Guido van Rossum. 

## 🎨 **NEW: Stunning Visual Interface**

ChronoCoder now features a **beautiful graphical mentor selection interface** with:
- 🎨 **Unique banners and color schemes** for each mentor
- ✨ **Gradient backgrounds and hover animations**
- 📱 **Mobile-responsive design** for all devices
- 🎭 **Custom icons and personalities** for each mentor
- 🎯 **Smooth transitions and professional typography**

Users can now:
- Select mentors through an elegant visual interface
- Receive personalized feedback in each mentor's unique teaching style
- Access the app from any browser (desktop, mobile, tablet)
- Enjoy easter eggs and special responses
- Use advanced admin features (for Anubhav)

## 👨‍💻 Tech Stack
- Python 3.10+
- Streamlit (for web interface)
- AST module (for code parsing)
- Modular file structure: `main.py`, `mentors.py`, `code_parser.py`

## 🗂️ Project Structure

```
ChronoCoder/
├── main.py              # App entry point (UI + control)
├── mentors.py           # Mentor tone and templates
├── code_parser.py       # AST-based code analysis
├── utils.py             # (optional) helper functions
├── logs/                # user session logs
├── requirements.txt     # Python dependencies
└── README.md           # This file
```
