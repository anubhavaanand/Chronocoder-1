Design system for a retro computing educational platform with 8 legendary programmer personas from 1940s-1990s.

## Brand Identity: "The ChronoCoder Archive"
A museum/archive experience celebrating computing history through interactive exhibits.

## Visual Style: Retro Computing Theme (1980s-1990s aesthetic)
- Primary Colors: Deep charcoal background (#1a1a2e), neon cyan (#00f3ff), electric magenta (#ff00ff), amber terminal (#ffb000), matrix green (#00ff41)
- Typography: 
  - Display: 'Press Start 2P' or 'VT323' for retro gaming feel
  - Body: 'Inter' or 'Roboto' for readability
  - Code: 'JetBrains Mono' or 'Fira Code' for programming
- Gradients: Neon glow effects, cyberpunk-inspired color transitions
- Shapes: Geometric shapes, circuit board patterns, pixel art elements
- Icons: Pixelated icons, retro-futuristic symbols

## Component Library Requirements:

### Navigation Components:
1. Mega menu with glassmorphism effect on dark background
2. Breadcrumb navigation with retro tech styling
3. Tabbed interface with glowing underline indicators

### Card Components:
1. Exhibit cards (8 mentor personalities) with holographic hover effects
2. Glassmorphic cards for code analysis results
3. Terminal-style cards showing mentor feedback
4. Gradient border cards that glow on hover

### Interactive Elements:
1. Buttons with neon borders and pulse animations
2. Text inputs with blinking cursor effect
3. Dropdown selects with retro dropdown arrows
4. Checkboxes styled as toggle switches
5. Radio buttons with circular neon indicators

### Data Visualization:
1. Circuit board pattern backgrounds
2. Animated data flow visualizations
3. Progress bars styled as old monitor status indicators
4. Stats display in digital clock font

### Feedback Components:
1. Toast notifications styled as terminal output
2. Loading spinners with rotating gear patterns
3. Success/error messages with retro LED styling
4. Tooltips with pixelated borders

### Special Effects:
1. CRT monitor scanline overlay option
2. Screen flicker animations (optional, accessibility-friendly)
3. Glitch effects on hover states
4. Glow shadows for depth

## Color Palette:
- Background: #1a1a2e (dark blue-grey)
- Surface: #16213e (medium dark blue)
- Primary: #00f3ff (cyan)
- Secondary: #ff00ff (magenta)
- Accent 1: #ffb000 (amber)
- Accent 2: #00ff41 (matrix green)
- Text Light: #eaeaea
- Text Muted: #8b8b8b
- Border: rgba(0, 243, 255, 0.2)

## Animation Guidelines:
- Smooth transitions (200-400ms)
- Hover states with neon glow expansion
- Scroll-triggered animations for exhibit reveals
- Loading sequences with retro boot-up style
- Micro-interactions mimicking vintage computer responses

## Accessibility:
- Respect prefers-reduced-motion
- High contrast mode toggle
- Keyboard navigation with visible focus rings
- ARIA labels for all interactive elements
- Screen reader friendly mentor descriptions
